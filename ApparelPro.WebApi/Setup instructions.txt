

How to Re-Run Your MigrationsOnce you update the connection string, you need to wipe out the current 
empty database structure and let EF Core build it perfectly from scratch.

Open your Package Manager Console in Visual Studio.Completely delete the current 
problematic database structure by running:shell

Drop-Database -Context ApparelProDbContext 

Re-apply all your historical code-first migrations to build the tables fresh:shell

there are 2 contetxts - ApparelProDbContext and UserIdentityDbContext

Update-Database -Context ApparelProDbContext 
Update-Database -Context UserIdentityDbContext

If you are using the .NET CLI in terminal instead of Visual Studio, use these commands:shell

dotnet ef database drop

dotnet ef database update -Context ApparelProDbContext
